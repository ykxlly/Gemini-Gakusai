# Step 1 — 情報設計とコピー（2026-10-03 改訂版）

当日運用向けに再設計した IA と文言の一元管理メモ。最新版は本書と `IMPLEMENTATION_STATUS.md`。

## 直線フロー（S0 → S1 → S2 → S3）

```
S0 TOP（気分→目的→同行者）
  └─ おみくじを引く（鈴绪演出）
S1 結果（ResultHero）
  ├─ 企画 hero: 企画名・場所・時間・料金・定員・案内
  ├─ 道しるべ（S103 → 目的地）
  ├─ 今日の三歩（RallyProgress）: 一 運勢 / 二 寄り道 / 三 S103で受け取り
  └─ 次にやること: ボタン 1 つだけ大きく
S2 現地ミッション（MissionPanel）
  ├─ 企画名・場所・やること
  └─ 大きい「行きました！」→ 紙吹雪 → S3 へ
S3 完了（RewardPanel）
  ├─ 御朱印風スタンプ「寄り道 達成」
  ├─ 「S103に来てね！」（最大サイズ）
  ├─ 「ステッカーとトートバッグをプレゼント」
  ├─ 「この画面をスタッフに見せてください」
  └─ 達成した企画と達成時刻（スタッフの目視確認用）
```

裏動線: 「思い出を開く」FAB（結果画面以降のみ表示）→ 音声・お守りカード・チャット・今日のまとめ・しおり（テキスト版）。

## 削除された機能（旧設計からの差分）

- なぞなぞ（ローカル正規化 + `/api/omikuji/riddle`）→ 廃止
- お題フォトラリー・発見カメラ（`/api/omikuji/verify`）→ 廃止
- 発見カードの件数条件・交換ボタン・受付番号・スタッフ承認キー・`/api/novelty/claim`（Supabase）→ 廃止
- `?booth=novelty` ブースモード → 廃止（完了画面と矛盾するため）
- 思い出シートの写真欄・発見カード一覧 → 廃止（しおりはテキスト版に）

## 文言の管理

- 全 UI 文言は `src/lib/copy.ts` に一元管理。
- 会場名「S103」は `RECEIVE_SPOT` 定数 1 か所。会場変更時はここだけ直す。
- 進捗の文言は `copy.progress`、完了画面は `copy.reward`、ミッションは `copy.mission`。

## 永続化

- `omikuji-history`（運勢名とメッセージ、最大 10 件）のみ。サーバー保存なし、ユーザー認証なし。
- 達成状態（`missionComplete` / 達成企画・時刻）はセッション内の state のみ。ページ再読込で消える（当日の運用はスタッフの目視確認で担保）。
