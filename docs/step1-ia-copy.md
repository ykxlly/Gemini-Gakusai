# Step 1 — 情報設計とコピー（2026-10-03 方針変更後）

「引いて → おすすめの場所を見て → 終わり」の2画面IA。最新版は本書と `IMPLEMENTATION_STATUS.md`。

## 直線フロー（S0 → S1）

```
S0 TOP（TopForm）
  ├─ 気分 → 目的 → 同行者（3問）
  ├─ ニックネーム（任意・10文字まで・保存しない）
  ├─ MBTI・同行者の気分（任意・details内）
  └─ 鈴緒を引いて授かる（演出）
S1 結果（ResultHero）← ゴール
  ├─ 運勢（固定一覧から重み付き抽選・筆文字で大きく）＋今日のひと言
  ├─ AIのパーソナルメッセージ（入力を引用）
  ├─ 「〇〇さんにおすすめの場所はここ！」
  │    企画名（最大）・場所（教室名・目立たせる）・おすすめの理由・時間/料金/定員/案内
  ├─ ほかにもおすすめ（2件：企画名＋場所＋理由1行）
  ├─ ラッキーカラー・ラッキーフード（＋相性コメント：同行者の気分入力時）
  └─ 「もう一回引く」「結果をシェア」
```

裏動線: 「思い出を開く」FAB（結果画面以降のみ表示）→ 音声・お守りカード・チャット・今日のまとめ・しおり（テキスト版）。

## 文言の管理

- 全 UI 文言は `src/lib/copy.ts` に一元管理。
- 運勢一覧は `src/lib/fortune.ts` の `FORTUNES` 定数（Googleネタ24種・凶なし）。重みは `TIER_WEIGHTS`。
- おすすめの呼びかけは `copy.result.recommendHeading(nickname)`（ニックネーム未入力なら「あなたに」）。

## 永続化

- `omikuji-history`（運勢名とメッセージ、最大 10 件）のみ。サーバー保存なし、ユーザー認証なし。
- ニックネームは永続化しない。
