# 超パーソナル AI おみくじ（BDSF 寄り道おみくじ）

学園祭の来場者向けに、気分から「おすすめの場所」を導き出す Next.js アプリです。

## 当日のフロー（これが正）

1. **TOP**：気分 → 目的 → 同行者（ニックネームとMBTIは任意）
2. **おみくじを引く演出**：鈴緒を引いて授与
3. **結果画面**：運勢（Googleネタ一覧・重み付き抽選）＋「あなたにおすすめの場所はここ！」← ゴール
4. **「もう一回引く」「結果をシェア」で終わり**

ミッション・印集め・S103 でのノベルティ交換はありません。ノベルティはブース来場時に全員へ配布します。

## 結果画面の構成（上から）

1. 運勢（大きく・筆文字フォント）＋今日のひと言＋AIのパーソナルメッセージ
2. 「〇〇さんにおすすめの場所はここ！」：企画名（最大）・場所（教室名・目立たせる）・おすすめの理由（入力を引用）・時間/料金/定員/案内（データがある場合のみ）
3. ほかにもおすすめ（2件・小さめ：企画名＋場所＋理由1行）
4. ラッキーカラー・ラッキーフード（＋同行者の気分があれば相性コメント）
5. 「もう一回引く」「結果をシェア」

## ローカルで起動

1. `npm ci`
2. `.env.example` を `.env.local` にコピーし、`GEMINI_API_KEY`（と任意で `GROQ_API_KEY`）を設定
3. `npm run dev`

`npm run lint` と `npm run build` で静的検査と本番ビルドを確認できます。

## デプロイ

Vercel が `ykxlly/Gemini-Gakusai` の `main` と連携済み。`main` に push すると本番（gemini-gakusai.vercel.app）へ自動デプロイされます。必要な環境変数は `GEMINI_API_KEY`（必須）と `GROQ_API_KEY`（フォールバック・任意）のみ。

## 実装メモ

- **おすすめの選定はサーバー側**：気分・目的・同行者でカテゴリ重みを付け（例：のんびり→体験・マルシェ、家族→縁日）、上位6候補からランダムに1件＋代案2件を選ぶ。全34企画が候補で、同じ入力でも毎回違う場所が出る。AIは理由の文章だけを書く（企画名・場所は絶対に捏造しない）。
- **運勢は固定一覧**：Googleネタの24種を `fortune.ts` に定数で保持し、サーバーが重み付きランダムで抽選（超大吉1% / 大吉30% / 中吉30% / 小吉25% / 末吉14%）。凶はなし。超大吉は紙吹雪多めの特別演出。AIは運勢に合わせた message だけを書く。
- **ニックネーム**：任意・10文字まで・保存しない（AIの呼びかけにのみ使用）。
- フォントは `next/font/google` で自己ホスト：見出し・ボタン・数字は **Dela Gothic One**、本文は **Zen Maru Gothic**。`preload: false`・`display: swap`・2種類のみ。
